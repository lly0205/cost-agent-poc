## 一、工程量计算（算量）

### 1.1 任务描述
根据施工图纸，按照计量规范计算各分项工程的实物工程量。

### 1.2 主要工作内容
- 读取并理解施工图纸（建筑、结构、机电等）
- 按专业分工进行工程量计算（土建、装修、安装、市政等）
- 编制工程量计算书（含计算式和图纸依据）
- 核对不同专业图纸间的数据一致性

### 1.3 主要依据
- 施工图纸（建施、结施、水施、电施等）
- 工程量计算规范（如 GB 50854 等系列规范）
- 项目所在地地方定额
- 设计说明、图纸会审纪要、变更通知

### 1.4 常用工具
- 广联达 GTJ（土建算量）
- 广联达 GQI（安装算量）
- 斯维尔算量系列
- Excel 手工算量
- CAD 测量工具

### 1.5 AI 辅助场景
- 从 PDF/文字描述中提取关键尺寸
- 辅助计算简单几何体工程量
- 检查计算式是否有明显错误
- 汇总多个房间/楼层的工程量

## 二、工程量清单编制与复核

### 2.1 任务描述
依据工程量计算结果，按清单规范格式编制工程量清单（BOQ），或对已有清单进行复核。

### 2.2 主要工作内容
- 将工程量计算结果整理成标准清单格式
- 编写项目特征描述（材料、规格、做法、质量标准等）
- 套用清单编码（通常按 GB 50500 及省市补充定额）
- 检查清单的完整性、准确性和规范性
- 招标清单审核（防止漏项、模糊描述、不平衡报价风险）

### 2.3 清单格式要素
| 要素 | 说明 |
|------|------|
| 项目编码 | 12 位编码（前 9 位统一，后 3 位企业自定） |
| 项目名称 | 简洁准确 |
| 项目特征 | 决定综合单价的关键因素 |
| 计量单位 | m、m²、m³、kg、套、台、项等 |
| 工程量 | 按规范计算规则的数量 |

## 三、图纸会审 / 图纸审阅

### 3.1 任务描述
在算量或编制清单前，对施工图纸进行审阅，发现问题并提出疑问。

### 3.2 主要检查内容
- 图纸完整性：是否有缺图、版本问题
- 图纸可读性：标注是否清楚、比例是否正确
- 不同专业图纸的协调性（建筑 vs 结构 vs 机电）
- 设计与规范的一致性（不涉及违规判断，仅提出疑问）
- 对工程量有重大影响的信息是否清晰

### 3.3 AI 辅助场景
- 从文字描述的图纸信息中提取关键数据
- 检查图纸清单（目录）的完整性
- 识别描述中的矛盾和不清晰点

## 四、招投标清单检查

### 4.1 任务描述
在招标阶段，对业主提供的招标清单进行审查，发现潜在风险。

### 4.2 主要检查内容
- 清单漏项（可能导致结算追加）
- 项目描述模糊（可能引发争议）
- 计量单位错误
- 暂列金额和暂估价是否合理
- 不平衡报价风险识别

## 五、变更签证审核

### 5.1 任务描述
对施工过程中发生的工程变更和现场签证进行审核和整理。

### 5.2 主要工作内容
- 审核变更内容的合同依据
- 计算变更引起的工程量增减
- 核实签证的合法性（签字、日期、依据）
- 评估变更对总价的影响
- 整理变更/签证台账

### 5.3 常见问题
- 变更通知单与实际施工不符
- 签证缺少关键签字（监理/业主）
- 变更内容超出合同范围未走审批程序
- 重复签证（同一内容签了多次）

## 六、结算审核

### 6.1 任务描述
工程竣工后，对承包商提交的结算文件进行审核。

### 6.2 主要审核内容
- 合同范围内工程量复核
- 变更/签证工程量确认
- 单价合规性（是否按合同约定）
- 暂估价确认
- 争议项目处理

## 七、定额套用 / 清单计价

### 7.1 任务描述
根据工程量清单，套用相应定额或综合单价，计算工程造价。

### 7.2 主要工作内容
- 分析清单项目特征，选择对应定额子目
- 调整定额含量（换算）
- 计算综合单价（直接费、管理费、利润、税金）
- 编制综合单价分析表

### 7.3 定额类型（通用分类）
- 预算定额（综合单价基础）
- 概算定额（可研/初设阶段）
- 估算指标（可研阶段）

## 八、材料设备询价和价格复核

### 8.1 任务描述
收集材料设备市场价格，用于编制综合单价或核实承包商报价。

### 8.2 主要工作内容
- 收集当地市场信息价
- 向供应商询价
- 对比市场价与清单单价的合理性
- 甲供材料价格确认

## 附录：常用术语

| 术语 | 说明 |
|------|------|
| BOQ | Bill of Quantities，工程量清单 |
| 综合单价 | 含直接费、管理费、利润的单价（不含税） |
| 暂列金额 | 用于可能发生的工程量变化的备用金 |
| 暂估价 | 暂时估定的材料/设备单价，后续确认 |
| 措施费 | 非实体项目费用（如脚手架、模板等） |
| 规费 | 社保、公积金等法定费用 |
| 税金 | 增值税（目前建筑业一般纳税人税率 9%）|

> **免责说明**：以上税率等数字为示例，以项目执行时的实际政策为准。
