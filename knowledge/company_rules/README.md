# 公司算量规则

> 本目录存放公司内部的算量规则和惯例。
> **由造价师团队负责维护和补充。**

## 目录说明

每个文件对应一类规则，建议命名格式：
- `decoration_rules.md` — 装修工程算量惯例
- `civil_rules.md` — 土建工程算量惯例
- `mep_rules.md` — 机电安装算量惯例
- `pricing_rules.md` — 计价和费率惯例
