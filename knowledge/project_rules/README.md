# 项目级特殊规则

> 本目录存放特定项目的特殊规则和约定。
> 每个项目一个子目录，命名为项目编号或项目简称。

## 目录结构示例

```
project_rules/
├── proj_2024_001/
│   ├── project_brief.md      # 项目概述
│   ├── special_rules.md      # 特殊算量约定
│   └── contract_notes.md     # 合同相关注意事项（不含机密）
└── proj_2024_002/
    └── ...
```
