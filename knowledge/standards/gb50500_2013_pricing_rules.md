# GB50500-2013 建设工程工程量清单计价规范
> 来源：GB50500-2013《建设工程工程量清单计价规范》（含专业、附录及条文说明）
> 适用于建设工程施工发承包计价活动。
> 注意：2024版新标准（GB/T 50500-2024）已于2025-09-01起实施，如项目合同、招标文件另有约定，以约定为准。

---

## 一、核心术语定义

| 术语 | 定义 |
|------|------|
| 工程量清单 | 建设工程的分部分项工程项目、措施项目、其他项目、规费项目和税金项目的名称和相应数量等的明细清单 |
| 综合单价 | 完成一个规定计量单位的分部分项工程和措施清单项目所需的**人工费、材料和工程设备费、施工机具使用费和企业管理费、利润**以及一定范围内的**风险费用** |
| 暂列金额 | 招标人在工程量清单中暂定并包括在合同价款中的一笔款项，用于施工中可能发生的工程变更、合同约定调整因素等 |
| 暂估价 | 招标人在工程量清单中提供的用于支付必然发生但暂时不能确定价格的材料、工程设备的单价以及专业工程的金额 |
| 计日工 | 在施工过程中，承包人完成发包人提出的施工图纸以外的零星项目或工作，按合同中约定的综合单价计价的一种方式 |
| 招标控制价 | 招标人根据国家或省级、行业建设主管部门颁发的有关计价依据和办法编制的招标工程**最高限价** |
| 工程量偏差 | 承包人实际完成的工程量与招标工程量清单列出的工程量之间的偏差 |
| 竣工结算价 | 发、承包双方依据国家有关法律、法规和标准规定，按照合同约定确定的合同总金额 |

## 二、计价方式（第3章）

### 2.1 费用构成

建设工程施工发承包造价由以下五项组成：

```
合同总价 = 分部分项工程费 + 措施项目费 + 其他项目费 + 规费 + 税金
```

- **分部分项工程费**：采用综合单价计价
- **措施项目费**：采用综合单价计价；安全文明施工费不得作为竞争性费用
- **其他项目费**：暂列金额 + 暂估价 + 计日工 + 总承包服务费
- **规费**：社会保障费（养老/失业/医疗）+ 住房公积金 + 工程排污费 + 工伤保险；不得作为竞争性费用
- **税金**：营业税 + 城市维护建设税 + 教育费附加（注：现已改为增值税体系，以项目执行时政策为准）

### 2.2 计价风险分担原则

| 风险类型 | 承担方 | 备注 |
|---------|--------|------|
| 国家法律法规变化 | 发包人 | 以投标截止日前28天为基准日（招标工程） |
| 省级或行业建设主管部门发布的人工费调整 | 发包人 | |
| 材料设备价格涨幅>招标基准价5% | 发包人承担超出部分 | 无约定时适用 |
| 施工机械使用费涨幅>招标基准价10% | 发包人承担超出部分 | 无约定时适用 |
| 承包人自身原因施工费用增加 | 承包人全部承担 | |

## 三、工程量清单编制规则（第4章）

### 3.1 基本要求

- 招标工程量清单**必须**作为招标文件的组成部分，其**准确性和完整性由招标人负责**
- 工程量清单由五部分组成：分部分项工程量清单、措施项目清单、其他项目清单、规费项目清单、税金项目清单
- 编制工程量清单应依据：本规范和相关工程的国家计量规范、计价依据和办法、建设工程设计文件、标准规范技术资料、拟定的招标文件、施工现场情况

### 3.2 分部分项工程量清单五要素（必须全部载明）

| 要素 | 说明 |
|------|------|
| 项目编码 | 12位编码（前9位统一，后3位企业自定）；全部为阿拉伯数字 |
| 项目名称 | 以工程量计算规范的项目名称为基础，结合具体工程的特征确定 |
| 项目特征 | 构成清单项目、反映其本质特征的主要内容——**决定综合单价的关键要素** |
| 计量单位 | 按工程量计算规范规定采用，精度要求见规范附录 |
| 工程量 | 按工程量计算规范规定的工程量计算规则计算 |

### 3.3 项目特征描述要求

项目特征是影响综合单价的核心。必须按工程量计算规范中各清单项目的项目特征描述要求，结合技术规范、标准图集、施工图纸逐项填写，不得省略影响综合单价的内容。

常见应描述内容：
- 材料品种、规格、强度等级
- 施工工艺、做法标准
- 构件尺寸（如截面尺寸、厚度等）
- 质量要求、检验标准

### 3.4 措施项目

- 按相关工程现行国家计量规范的规定编制
- 根据拟建工程的实际情况列项
- 安全文明施工费不得作为竞争性费用，投标人不得删除

### 3.5 工程量计算规则总原则

- 工程量应按照**相关工程的现行国家计量规范**规定的工程量计算规则计算
- 工程量计算应以设计图示尺寸为准
- 以实体尺寸和净尺寸计算，不得包含施工操作裕量

---

## 四、招标控制价（第5章）

### 4.1 适用规则

- **国有资金投资**的工程建设项目应实行工程量清单招标，招标人**应编制**招标控制价
- 招标控制价**超过批准概算**的，须报原概算审批部门审核
- 投标报价高于招标控制价的，投标**应予拒绝**
- 招标控制价应在招标时**公布**，不应上调或下浮

### 4.2 招标控制价复查规则

- 投标人认为招标控制价编制不符合规范，应在**控制价公布后5天内**向相关机构投诉
- 工程造价管理机构受理投诉后，应在**10天内**完成复查
- 复查结论与原公布控制价误差**>±3%**的，应责成招标人改正

---

## 五、投标报价（第6章）

### 5.1 主要规则

- 投标报价**不得低于工程成本**
- 投标人应按招标工程量清单填报价格；项目编码、项目名称、项目特征、计量单位、工程量**必须与招标工程量清单一致**
- 未填写单价和合价的项目，视为此项费用已包含在已标价工程量清单中其他项目中，竣工结算时不得重新组价调整
- 投标总价应与分部分项工程费、措施项目费、其他项目费和规费、税金的合计金额**一致**

---

## 六、工程计量（第8章）

### 6.1 基本原则

- 工程量应按照相关工程的**现行国家计量规范**规定的工程量计算规则计算
- 计量可选择按**月或按工程形象进度**分段计量，具体在合同中约定
- 因承包人原因造成的超范围施工或返工的工程量，发包人**不予计量**

### 6.2 单价合同计量程序

1. 承包人按计量周期（合同约定）向发包人提交**已完工程量报告**
2. 发包人应在收到报告后**7天内核实**并通知承包人
3. 发包人未在7天内核实的，承包人报告中的工程量视为**已认可**
4. 承包人认为计量结果有误，应在收到结果通知后**7天内**提出书面意见
5. 合同工程完成后，发承包双方应对每个项目历次计量报表汇总，核实**最终结算工程量**

### 6.3 总价合同计量

- 以总价为基础，工程量是进行工程目标管理和控制进度支付的依据
- 除按发包人工程变更规定引起的工程量增减外，各项目的工程量是承包人用于结算的**最终工程量**

## 七、合同价款调整（第9章）

### 7.1 价款调整触发事项

以下事项发生，发承包双方应按合同约定调整合同价款：

1. 法律法规变化
2. 工程变更
3. 项目特征描述不符
4. 工程量清单缺项
5. 工程量偏差
6. 物价变化
7. 暂估价确认
8. 计日工
9. 现场签证
10. 不可抗力
11. 提前竣工（赶工补偿）
12. 误期赔偿
13. 施工索赔
14. 暂列金额

### 7.2 工程变更价款调整规则

**调整原则（三档）：**

| 情形 | 处理方式 |
|------|---------|
| 清单中有适用项目且工程量偏差≤15% | 采用该项目的综合单价 |
| 清单中无适用但有类似项目 | 在合理范围内参照类似项目单价 |
| 清单中无适用也无类似项目 | 承包人根据变更工程资料、计量规则、计价办法提出单价，经发包人确认后调整 |

**变更工程综合单价偏差调整（超出15%时）：**
- 当 P0 < P1×(1-L)×(1-15%) 时，按 P1×(1-L)×(1-15%) 调整
- 当 P0 > P1×(1+15%) 时，按 P1×(1+15%) 调整
  - P0 = 承包人在工程量清单中填报的综合单价
  - P1 = 发包人招标控制价或施工图预算中相应清单项目的综合单价
  - L = 承包人报价浮动率

### 7.3 工程量偏差调整规则（15%临界点）

当工程量偏差超过15%时调整综合单价：

| 情形 | 结算公式 |
|------|---------|
| Q1 > 1.15Q0（工程量增加>15%） | S = 1.15Q0 × P0 + (Q1 - 1.15Q0) × P1 |
| Q1 < 0.85Q0（工程量减少>15%） | S = Q1 × P1 |

其中：S=结算价，Q1=最终完成工程量，Q0=清单工程量，P1=重新调整后的综合单价，P0=填报的综合单价

### 7.4 物价变化调整

- 人工单价变化：按实际人工数量和价差计算，或按人工费调整系数计算
- 材料设备单价变化**超过5%**：超出部分由发包人承担（合同无约定时适用）
- 施工机械台班单价变化**超过10%**：超出部分由发包人承担（合同无约定时适用）

### 7.5 施工索赔程序

| 步骤 | 时限 | 内容 |
|------|------|------|
| 索赔意向通知 | 索赔事件发生后**28天内** | 向发包人提交，说明索赔事由；逾期丧失索赔权利 |
| 正式索赔通知 | 发出意向通知后**28天内** | 详细说明索赔理由和要求，附必要记录和证明材料 |
| 延续索赔通知 | 连续影响期间持续提交 | 说明连续影响的实际情况和记录 |
| 最终索赔通知 | 索赔事件影响结束后**28天内** | 提交最终索赔要求 |
| 发包人答复 | 收到索赔通知书后**28天内** | 逾期未答复视为已认可 |

## 八、竣工结算（第11章）

### 8.1 结算编制时限

| 事项 | 时限 |
|------|------|
| 承包人提交竣工结算文件 | 竣工验收申请提交的同时 |
| 发包人审核完毕 | 收到文件后**28天内** |
| 发包人复核补充材料后 | **28天内**再次复核 |
| 无异议确认 | **7天内**签字确认 |
| 发包人不审核或未提意见 | 视为**认可**，竣工结算办理完毕 |

**注意**：承包人逾期未提交结算文件，经发包人催促后14天内仍未提交的，发包人有权根据已有资料自行编制竣工结算文件。

### 8.2 结算款支付

- 发包人应在收到竣工结算款支付申请后**7天内**核实，签发支付证书
- 应在签发支付证书后**14天内**支付结算款
- 结算支付证书签发后**56天**内仍未支付，承包人可向人民法院申请将该工程依法拍卖；承包人就折价或拍卖的价款**优先受偿**

### 8.3 质量保证金

- 按合同约定从每支付期的进度款或结算款中扣留，直到达到约定金额
- 保修责任期终止后**14天内**，发包人应将剩余质量保证金返还给承包人

## 十、工程量清单编制注意事项（Agent 专用规则）

1. **编码唯一性**：同一工程中同一清单项目的编码必须唯一，不得重复
2. **特征完整性**：项目特征描述必须涵盖影响综合单价的全部要素；若描述不全，承包商可拒绝按综合单价承担风险
3. **漏项责任**：清单漏项由招标人负责；漏项引起的新增项，按本规范第9.5条确定单价
4. **描述不符处理**：实际施工与项目特征描述不符时，按实际施工的项目特征重新确定综合单价，调整合同价款
5. **暂估价标识**：设备和材料暂估价必须在清单中明确标识，不得隐含
6. **措施费竞争性**：安全文明施工费、规费、税金不得作为竞争性费用

## 十一、附录参考——各专业清单编制规则摘要

### 11.1 附录A 土石方工程（0101）
- 平整场地：按**首层建筑面积**计算
- 挖沟槽/基坑/一般土方：底宽≤7m且底长>3倍底宽为沟槽；底长≤3倍底宽且底面积≤150m²为基坑；其余为一般土方
- 回填方：室内按主墙间面积×厚度，不扣间隔墙；基础回填 = 挖方体积 - 地坪以下基础体积
- 余方弃置：挖方量 - 回填方量（取正值）

### 11.2 附录C 桩基工程（0103）
- 桩长：含桩尖
- 预制桩、灌注桩：按设计桩长（含桩尖）以**延长米/根/体积**计算
- 截（凿）桩头：按桩截面积×桩头长度以体积计算

### 11.3 附录D 砌筑工程（0104）
- 砖基础与墙身分界：同材料以设计室内地面为界（以下基础，以上墙身）；不同材料以材料分界面为界
- 砌体墙工程量：扣除门窗洞口、嵌入RC构件体积；不扣钢筋铁件、管道及≤0.3㎡的孔洞
- 框架间墙：按墙体净尺寸计算

### 11.4 附录E 混凝土及钢筋混凝土工程（0105）
**柱高度计算（含强制规则）：**
- 框架柱、构造柱：**必须扣除现浇楼板板厚，按净高计算**（本项目Rule 1）
- 有梁板：柱高=柱基上表面至上一层楼板上表面
- 无梁板：柱高=柱基上表面至柱帽下表面
- 框架柱：柱高=柱基上表面至柱顶

**梁：**
- 梁高从板底到梁底面（不含板厚）
- 与柱相交时：梁长算至柱侧面

**板：**
- 有梁板（含主次梁与板）：梁+板体积合并计算
- 无梁板：板+柱帽体积之和

**钢筋：**
- 按**设计图示长度**（含设计标注的锚固）×理论单重计算，以吨计量
- 伸出构件的锚固钢筋并入工程量
- 施工搭接（设计未标注）不另计工程量，在综合单价中考虑

**不扣除规定：**
- 不扣除构件内钢筋、预埋铁件及单个面积≤0.3㎡的柱、垛及孔洞

### 11.5 附录H 门窗工程（0108）
- 门窗工程量按**门窗洞口面积**以㎡计算，或按**樘**计算
- 所有门窗洞口尺寸必须取自图纸《门窗表》，不得自行估算（本项目Rule 2）
- 门窗套按展开面积计算

### 11.6 附录I 屋面及防水工程（0109）
- 屋面卷材/涂膜防水：按**设计图示面积**计算
- 楼地面防水：按主墙间净空面积计算，扣除凸出地面的构筑物、设备基础等；不扣除间壁墙及≤0.3㎡柱、垛、烟囱和孔洞
- 防水反边高度≤300mm算作地面防水；反边高度>300mm算作墙面防水

### 11.7 附录J 保温隔热工程（011001）
- 保温隔热屋面/天棚/楼地面：按设计图示面积，扣除面积>0.3㎡的孔洞及占位面积
- 保温隔热墙面：扣除门窗洞口以及面积>0.3㎡梁、孔洞所占面积；门窗洞口侧壁需作保温时，并入保温墙体工程量
- 保温柱：按柱断面保温层中心线展开长度×保温层高度以面积计算

### 11.8 附录K 楼地面装饰工程（0111）
- 水泥砂浆楼地面、石材楼地面：按设计图示面积计算
- 楼梯面层：按水平投影面积计算
- 台阶装饰：按水平投影面积计算

### 11.9 附录L 墙柱面装饰工程（0112）
- 外墙抹灰：按**垂直投影面积**计算；扣除门窗洞口及单个>0.3㎡孔洞面积；不扣踢脚线、挂镜线及墙与构件交接处；洞口侧壁不增加
- 内墙抹灰：按主墙间净长×净高；无墙裙：地面至天棚底；有墙裙：墙裙顶至天棚底

### 11.10 附录M 天棚工程（0113）
- 天棚抹灰、吊顶天棚：按**水平投影面积**计算

### 11.11 附录Q 措施项目（0117）
- 综合脚手架：按**建筑面积**（按GB/T 50353计算）计算
- 混凝土模板及支架：按**与混凝土接触面积**计算
- 垂直运输：按**建筑面积**计算
