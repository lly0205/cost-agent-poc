# 土建工程图纸识图与构件清单抽取规则
> 来源：中国建设工程图纸识图与构件清单抽取逻辑_Agent规则版 V1.0（2026-06-02）
> 本文件为 Agent 图纸识别的强制执行规则库，优先级高于通用图形识别逻辑。

---

## 一、总原则（P1/P2/P3）

| 原则 | Agent 执行含义 |
|------|--------------|
| P1 先上下文、后图元 | 任何线、块、填充、文字，必须先放入「专业-图名-视图-楼层-轴网-比例-图例-说明」的上下文中解释。不能把线型直接等同于构件。 |
| P2 多证据闭环 | 构件输出至少应有两类证据支撑：如图层/块名+文字标注，几何形态+尺寸标注，图例+符号，平面位置+剖面高度，平面位置+节点大样，平面位置+墙身大样，平面位置+图集标准。仅凭单一视觉相似性时应降低置信度。 |
| P3 中国规范优先 | 制图语义、平法编号、工程量单位、清单划分，应按中国现行国家标准、国家建筑标准设计图集、地方计价依据、项目图例和设计说明执行。项目专用图例优先于行业习惯。 |

---

## 二、规范体系优先级

同一问题有冲突时，按以下优先级排序（高优先级覆盖低优先级）：

| 优先级 | 资料类型 | 说明 |
|--------|----------|------|
| 1 | 招标文件、合同专用条款、答疑纪要、变更洽商、业主确认文件 | 最高优先级，必须记录文件版本和日期 |
| 2 | 项目设计总说明、各专业设计说明、图纸目录、图例、材料做法表、门窗表、设备表 | 项目专用图例优先于国家标准和行业习惯 |
| 3 | 单张图纸的图名、标题栏、楼层、比例、轴网、局部说明、索引详图 | 局部说明优先于通用说明，索引详图优先于总说明详图 |
| 4 | 国家标准、国家建筑标准设计图集、行业标准、地方标准/定额 | 按项目所在地和项目时间采用对应版本 |
| 5 | CAD 图层、块名、颜色、线型、线宽、Xref 名称、模型对象属性 | 可信度受设计院制图习惯影响，不可单独定性 |
| 6 | 几何形状、视觉相似性、OCR/AI 推断 | 只能作为候选，不可作为最终构件判定唯一依据 |

**强制规则**：若国家标准、项目图例、设计说明和几何识别之间出现冲突，先报告冲突，不得静默采用视觉推断。输出时必须写明「采用依据」和「未采用依据」。

## 三、图纸读取流水线

```
图纸包/模型文件
  ↓
文件分类：专业、阶段、版本、图纸目录、设计说明、图例、表格
  ↓
单张图纸解析：标题栏 → 图名 → 专业 → 比例/单位 → 楼层/标高 → 轴网 → 视图类型
  ↓
图元抽取：线/多段线/圆弧/三角形/正方形/长方形/多边形/文字/尺寸/填充/表格/图例
  ↓
候选构件生成：几何聚合 + 文本绑定 + 图例匹配
  ↓
专业规则判定：建筑/结构/安装/室外/总图分别解释同一类图元
  ↓
跨图校核：平面定位、剖面高度、墙身大样、详图做法、表格规格、系统图连接
  ↓
去重与合并：典型层、详图、索引、重复 Xref、系统图重复表达
  ↓
构件清单输出：构件对象、规格、材质、数量初判、清单映射、证据、置信度、疑问项
```

## 四、单张图纸必须提取的元数据

| 元数据 | 作用 | 常见来源 |
|--------|------|---------|
| 图纸编号/专业代码 | 区分建施/结施/水施/暖施/电施/总施/装施；识别图纸阶段和版本 | 标题栏、文件名、图纸目录 |
| 图名 | 决定视图类型与构件语义（如"二层梁配筋平面图"和"二层建筑平面图"对线条解释完全不同） | 标题栏、图内大标题 |
| 楼层/标高/区域 | 构件定位和典型层倍数 | 图名、轴网、标高符号、剖面标注 |
| 比例/单位 | 矢量 PDF 或扫描图的尺寸换算；CAD 模型空间不可简单套用打印比例 | 标题栏、比例标注、尺寸标注反算 |
| 轴网/坐标 | 构件定位、跨图合并、同名构件去重 | 定位轴线、总图坐标、控制点 |
| 图例/说明版本 | 解释项目专用符号和缩写 | 设计说明、图例页、图内说明 |
| 索引关系 | 防止详图和总图重复计数；把规格补充回主构件 | 索引符号、详图编号、剖切符号 |
| 比例有效性 | 图纸是否注明【不按比例NTS】——NTS 图纸的尺寸必须来自标注，不可用比例尺换算 | 图内说明 |

## 五、视图类型及 Agent 用法

| 视图类型 | 语义 | Agent 用法 |
|----------|------|-----------|
| 平面图 | 水平剖切或投影；构件位置和水平尺寸最可靠 | 用于构件存在、平面定位、长度/面积初判 |
| 立面图 | 竖向投影；反映外立面、门窗高度、幕墙分格、标高 | 不直接重复统计平面中已计入的构件；用于高度/做法补充 |
| 剖面图 | 被剖切处构造和高度最可靠 | 用于层高、构件厚度、屋面/楼梯/基础竖向关系 |
| 详图/大样 | 局部放大；规格做法可靠，但通常不是新增构件 | 通过索引回填主构件属性；默认不独立计数 |
| 系统图 | 安装专业的系统连接、立管关系、设备编号 | 用于系统归属和竖向连接；长度需结合平面和层高 |
| 表格/清单/材料表 | 规格、型号、数量、做法集中表达 | 可作为强证据；需与平面符号逐项核对 |
| 标准图集引用 | 构造规则和做法 | 说明构件做法，不代表工程内数量 |

## 六、线型语义规则

**同线判定公式**：
> 构件语义 = 专业 + 图名 + 视图类型 + 图例/说明 + 文字标注 + 尺寸/标高 + 几何关系 + 周边构件关系。
> 缺少前三项时，禁止直接输出确定性构件；只能输出候选项并要求确认。

| 图元/线型 | 一般语义 | Agent 规则 |
|-----------|----------|-----------|
| 粗实线/加粗轮廓 | 主要可见轮廓、被剖切构件或主构件边界 | 先判专业和视图；仅凭粗细不可确定构件 |
| 中/细实线 | 可见轮廓、辅助线、设备/家具/管线/尺寸相关线 | 结合图例、文字、是否连接到系统/设备判断 |
| 虚线 | 不可见、上方/下方、预留、隐藏、中心、拆除/新建区分等 | 项目图例优先；不能把虚线构件默认为不计量 |
| 点划线/轴线 | 定位轴线、中心线、控制线 | 轴线通常不计入构件，但可作为定位证据 |
| 填充/剖面线 | 材料、被剖切面、区域、做法 | 填充本身不是构件；它是材质/范围证据 |
| 引出线/索引线 | 连接文字说明、编号、详图 | 需要绑定到最近/被指向构件，不作为构件 |
| 尺寸线/标高线 | 表达尺寸、标高、坡度、间距 | 用于换算数量和规格；不作为构件 |

## 七、证据权重体系

| 证据类型 | 建议权重 | 注意 |
|---------|---------|------|
| 图纸目录/标题栏/图名 | 1.00 | 缺失时禁止最终定性 |
| 设计说明/图例/材料表/构件表 | 0.95 | 与平面符号逐一核对 |
| 局部文字标注/引出线/编号 | 0.90 | OCR 识别错误要标注置信度 |
| 尺寸/标高/轴线定位 | 0.80 | 不同图纸尺寸矛盾时列疑问项 |
| 几何形态/线型/线宽/颜色 | 0.55 | 需要至少一个更强证据补强 |
| 扫描图 OCR/CV 推断 | 0.40 | 低清晰度必须人工复核 |

## 八、各专业构件识别规则

### 8.1 总图/室外工程
- 先识别坐标系统、北向、场地红线、建筑控制线、道路中心线、道路边线、地形标高、竖向设计标高、管线图例
- 总图中线条常以坐标和标高为核心，不能按单体建筑墙/梁逻辑解释
- 室外管线应按系统图例和管径/管材/井号识别，不可只按线型区分给水、雨水、污水、电力、通信
- 道路、铺装、绿化、围墙、挡土墙、台阶、坡道、检查井、雨水口、管沟等应分别生成构件对象

### 8.2 建筑专业
- 以建筑平面、立面、剖面、屋面、门窗表、材料做法表、详图为主要依据
- 建筑图中"墙、门窗、楼梯、洞口、屋面、装饰面层"的存在和范围通常较可靠；构件厚度、材质、做法需结合说明和详图

**建筑构件识别要点：**

| 构件 | 识别依据 | 输出字段 | 风险提示 |
|------|---------|---------|---------|
| 墙体/隔墙 | 平面中双线、墙厚、轴线关系、材料填充、墙体说明 | 墙段：楼层、轴线范围、长度、厚度、高度来源、材质/做法 | 家具线、栏杆线、管线、装饰分格线不得误识为墙 |
| 门/窗/洞口 | M/C/FM/FC 等编号、门窗表、洞口线、开启方向、立面/剖面高度 | 门窗洞口对象：编号、尺寸、材质、防火等级、数量 | 门窗表是规格强证据；平面符号是数量/位置证据 |
| 楼梯/坡道/台阶 | 踏步线、箭头、标高、剖面、详图 | 楼梯段、平台、栏杆扶手、坡道、台阶 | 楼梯平面可上下层重复表达，需按层合并 |
| 楼地面/墙面/天棚做法 | 房间名称、做法编号、材料表、装修表、填充范围 | 房间/区域面层构件，面积初判需扣除规则另算 | 仅有房间名不能推定具体做法，需做法表 |
| 屋面/防水/保温 | 屋面平面、坡向、排水、女儿墙、详图做法 | 屋面区域、防水、保温、找坡、排水构件候选 | 屋面详图不重复计数，只补充层次 |

### 8.3 装饰装修
- 以「房间/区域 + 做法编号 + 材料表 + 分格/铺装图 + 节点详图」共同判定，不能只看填充图案
- 同一墙体构件在建筑清单中是墙，在装饰清单中可能生成墙面抹灰、涂料、饰面砖、踢脚线、墙裙等多个做法对象
- 输出时应保留「基层构件」和「装饰做法」的关联，避免把面层识别为新的主体墙体

### 8.4 结构专业（平法逻辑优先）
- 结构图中构件编号和配筋标注是核心。Agent 应把结构图的线条解释为平法构件、结构构件边界或钢筋/构造表达
- 混凝土结构优先使用 22G101 系列的平面整体表示方法理解构件类别和标注

**结构构件识别要点：**

| 构件 | 识别依据 | 输出字段 | 风险提示 |
|------|---------|---------|---------|
| 柱 | KZ/KZZ/QZ/LZ/XZ 等编号；矩形/圆形截面；柱表；轴线交点 | 柱编号、楼层、轴线位置、截面、混凝土等级、配筋属性来源 | 编号习惯需以项目结构说明/柱表为准 |
| 剪力墙/边缘构件 | 墙身编号、墙厚、GBZ/YBZ/AZ/DZ 等边缘构件编号 | 墙段、边缘构件、洞口、连梁关系、墙厚和标高范围 | 墙身线、边缘构件线、洞口线需分层解释 |
| 梁 | KL/WKL/L/XL/LL/AL/BKL/KZL 等编号；集中标注/原位标注；跨数 | 梁段：编号、跨、轴线、截面 b×h、标高、配筋属性 | 梁线可能与建筑墙线重合，必须按结构图名和标注判定 |
| 板 | 板厚 h=、板块编号、钢筋标注、负筋/分布筋线、洞口 | 板区：楼层、边界、板厚、配筋/做法来源、洞口 | 钢筋线不是板边界；板边界需结合梁/墙/洞口 |
| 基础 | 桩、承台、独立基础、条形基础、筏板、基础梁、地梁、集水坑 | 基础构件、编号、尺寸、底标高、混凝土等级、桩长/桩径来源 | 基础详图和基础平面需合并，不重复计量 |

**结构专业特别规则**：平法编号和结构设计说明优先于视觉形态。看到「KL1(2) 300×600」这类标注时，Agent 应先识别为梁构件及其属性，而不是把线条拆成普通几何线。看到柱表、梁表、墙表、板配筋说明时，应建立「编号-规格-楼层范围」的映射表，再回填平面中的构件。

## 九、去重规则

| 场景 | 表现 | 去重规则 |
|------|------|---------|
| 典型层图名 | 如"3~18层平面图" | 按层数倍数展开，但需排除避难层、设备层、结构转换层、屋面层等非典型楼层 |
| 详图/大样 | 局部放大或标准构造 | 默认不新增数量，只补充规格、做法、节点构造 |
| 门窗表/设备表 | 表格集中列规格和数量 | 表内数量可作强证据；仍需核对平面符号是否遗漏或设计变更 |
| 重复 Xref/底图 | 同一底图被多专业引用 | 只在主专业计入；在其他专业作为定位背景 |
| 多专业底图叠加 | 建筑底图出现在安装图中 | 只在建筑专业计入；其他专业作为定位参考，不重复列入实体清单 |

## 十、冲突处理优先级

| 冲突类型 | 例子 | 处理规则 |
|----------|------|---------|
| 图纸版本冲突 | 同一图号不同日期/版本 | 采用最新版或合同指定版；旧版仅作历史记录 |
| 平面与表格冲突 | 平面 M1 统计 8 樘，门窗表写 10 樘 | 输出冲突；优先核对变更/详图/平面是否漏层 |
| 图例与图层冲突 | 图层名像给水，图例线型为消防 | 图例/说明优先，图层作为辅助证据 |
| 文字与几何冲突 | 标注 DN100，但图形连接到 DN80 系统 | 输出疑问项，记录两个证据，不自动修正 |
| 典型层范围冲突 | 图名 3~18 层，说明 3~17 层相同 | 以说明/目录为强证据，输出范围风险 |
| 建筑与结构冲突 | 建筑墙位与结构梁墙位不一致 | 按专业分别输出；最终构造需设计协调，不能擅自合并 |

## 十一、置信度分级

| 等级 | 条件 | 输出策略 |
|------|------|---------|
| 高（0.85~1.00） | 图名/专业明确；图例或标注明确；尺寸/编号/表格可交叉验证；无版本冲突 | 可进入构件清单，但仍标注证据来源 |
| 中（0.65~0.84） | 大部分证据成立，但缺少某些规格、材质、层高或局部有遮挡 | 进入清单并列出待补证字段 |
| 低（0.40~0.64） | 主要来自图形/线型/OCR；缺图例或标注；专业不明 | 只输出候选构件，不参与正式数量汇总 |
| 极低（<0.40） | 扫描模糊、线条断裂、文字不可读、上下文缺失 | 不输出为构件；进入人工识别清单 |

## 十二、强制规则清单（R01~R19）

| 编号 | 规则 |
|------|------|
| R01 | 先读取图纸目录和设计说明，再处理单张图纸 |
| R02 | 每张图纸先识别标题栏、图名、专业、版本、比例、楼层、视图类型 |
| R03 | 未识别专业和图名前，不得解释线条为具体构件 |
| R04 | 项目图例/说明优先于通用图例；通用图例优先于视觉相似性 |
| R05 | CAD 图层/块名为辅助证据，不是最终证据 |
| R06 | 扫描图识别置信度默认降低，并需要 OCR 原文证据 |
| R07 | 墙、梁、管、线槽、道路边线等不可跨专业混判 |
| R08 | 结构构件按平法编号、构件表、结构说明识别 |
| R09 | 安装系统按系统代号、管径/规格、设备连接和系统图识别 |
| R10 | 详图和系统图默认作为属性证据，不默认新增数量 |
| R11 | 典型层展开必须保留楼层明细和例外楼层 |
| R12 | 输出时必须给出证据来源和置信度 |
| R13 | 清单映射不确定时只给候选，不生成伪确定编码 |
| R14 | 冲突必须显性报告，不得覆盖 |
| R15 | 所有数量均标为"初判/待审核"，除非项目规则完整且已通过人工审核 |
| R16 | 图纸中出现【仅供参考】【示意】【概念设计】等表述时，相关构件不参与正式清单计量，仅输出为参考对象 |
| R17 | 项目设计说明中有明确不计量范围或甲供材料清单时，Agent 应在构件输出中标注计量归属（自行采购/甲供/暂估） |
| R18 | 对超出 Agent 知识范围的专业构件（特种设备、实验室专用设备、舞台机械等），输出【专业外构件-建议人工补充】标记，不强行类比映射 |
| R19 | 每次识别批次应输出识别统计摘要（总构件数、高/中/低/极低置信度占比、疑问项数量） |

## 十七、建筑平面图专项识别规则（R-ARC 系列）

> 来源：2026-06-03 实证沉淀，基于一层平面图识别任务（扫描件）
> 适用：建筑专业平面图（一层、标准层、屋面层等）；与第八节 8.2 建筑专业规则配套使用

| 规则编号 | 规则名称 | 规则内容 |
|---------|---------|---------|
| R-ARC-01 | 轴网优先确立 | 必须先完整提取横轴（数字轴）和纵轴（字母轴）编号及轴距；所有构件定位必须绑定到轴线交点或轴线范围；轴距必须来自尺寸标注，不能靠视觉估算 |
| R-ARC-02 | 外墙厚度取值 | 外墙厚度必须来自尺寸标注或设计说明；常见：240mm（一砖砌体）、200mm（混凝土）、300mm（保温复合）；扫描图无法读取标注时仅输出候选值，标注"待设计说明确认" |
| R-ARC-03 | 内墙厚度取值 | 隔墙厚度从墙线双线间距和标注读取；无标注时仅输出候选值（100/120/200mm 常见）并降低置信度至 0.50 |
| R-ARC-04 | 门窗统计规则 | 门编号 M+数字，窗编号 C+数字；平面图数量为主证据，门窗表为规格证据；两者冲突时输出疑问项；无门窗表时宽度可从洞口估算，高度不可推断 |
| R-ARC-05 | 楼梯识别规则 | 踏步线+上行箭头+剖断线三者同时出现才能确认楼梯；宽度从平面读取，级数和层高需结合楼梯剖面/详图；不得仅凭踏步线确定楼梯类型 |
| R-ARC-06 | 柱截面取值与净高 | 框架柱截面尺寸从柱表或平面标注读取；柱高度 = 层高 - 楼板厚度（净高，必须扣板厚）；层高来源：建筑立面/剖面；板厚来源：结构楼板配筋图；无柱表时截面为候选值 |
| R-ARC-07 | 砌体墙门窗扣减 | 砌体墙工程量必须扣除全部门、窗洞口体积/面积；洞口尺寸严格按《门窗表》取值，不得自行估算；无门窗表时洞口扣减列为待计算项，在疑问项中明确记录 |
| R-ARC-08 | 房间面积与做法绑定 | 每个房间须绑定房间名称+轴线范围+净面积（墙内面积）；地面/墙面/天棚做法须来自设计说明的"做法表"或"装修表"；无做法表时不得按房间名推断做法，列为待确认项 |

### 扫描图识别补充规定

| 情形 | 处理规则 |
|------|---------|
| 扫描分辨率低（模糊/变形） | 所有尺寸不可比例换算，只能来自标注文字；置信度上限 0.60 |
| 文字 OCR 识别不确定 | 在 evidence.text 字段中标注"OCR/目视推断，待核实" |
| 柱表/门窗表在同图内但不可读 | 输出"图内有表格但内容不可读"，列为疑问项 Q，置信度降至 0.40 |
| 图纸中有彩色房间填充 | 彩色区域为功能分区示意，不直接等同于地面做法；须结合做法表确认 |

### 本节规则与第十二节强制规则的关系

R-ARC 系列规则是第十二节 R01~R19 的建筑专业细化，执行优先级相同。
当 R-ARC 与 R01~R19 冲突时，应输出冲突说明，由注册造价师裁定。
