## 附件上传目录约定

所有用户上传的附件统一存放于：

```
<PROJECT_ROOT>/.cc-connect/attachments/{yyyyMMdd_HHmmss}/
```

规则：
1. 每次上传在 `.cc-connect/attachments/` 下创建一个以当前时间戳命名的新目录，格式为 `yyyyMMdd_HHmmss`（例：`20260604_143022`）。
2. 本次上传的所有文件统一放入该目录，不与其他批次混用。
3. 每次上传必须生成全新目录；同一秒内多次上传时，自动追加序号后缀（`_1`、`_2` ...）保证唯一。
4. 该约定由 `skills/attachment_upload_skill.py` 中的 `AttachmentUploadSkill` 统一管理，任何涉及附件接收的代码必须通过该 skill 创建目录，禁止手动指定路径或复用旧目录。

## 文件使用说明

### gb50854_2013_rules.md
用于算量任务（quantity_takeoff），包含：
- 项目强制规则（Rule 1 柱净高、Rule 2 砌体墙扣门窗）
- 附录A土石方 ~ 附录Q措施项目的详细算量规则

### gb50500_2013_pricing_rules.md
用于清单编制、BOQ 复核、合同价款相关任务，包含：
- 综合单价构成、费用组成
- 工程量清单五要素和项目特征描述规则
- 工程量偏差15%调整规则
- 施工索赔程序和时限
- 竣工结算时限规则
- 各附录专业清单计算规则摘要

### drawing_recognition_rules.md
用于图纸识读和构件清单抽取任务，包含：
- P1/P2/P3 总原则
- 规范体系优先级（6级）
- 图纸读取流水线
- 各专业构件识别要点（建筑/结构/装饰/总图）
- 证据权重体系
- 置信度分级（高/中/低/极低）
- R01~R19 强制规则
- 构件清单标准字段（JSON格式）
- 输出前审核闯关表

## 规范版本注意事项

- **GB50854-2013 vs GB/T 50854-2024**：2024 版已于 2025-09-01 起实施。现有规则文件基于 2013 版整理，项目特征和计算规则大体一致，但编码和部分规则有调整。
- **GB50500-2013 vs GB/T 50500-2024**：2024 版已于 2025-09-01 起实施。如项目合同、招标文件另有约定，以约定为准。
- AI 不得将本目录中的摘要作为"权威规范"引用，应注明"参考摘要，以正式规范为准"，所有结果须经注册造价工程师审核。
