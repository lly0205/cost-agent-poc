## 方法论增量（可入 SKILL.md 候选 R23）
- **多图框单模型空间 DXF**：先取 A0 图框 INSERT bbox 分 sheet 带，再按带分区提取
- **跨图叠合严禁直接用图框偏移**：各 sheet 平面位置不对齐（本例 S5 相对其他图偏 dx=6745, dy≠图框间距）。必须用各图共有图元（如砼墙层 bbox 角点）作锚点求每图偏移
- 梁提取：BEAM/BEAM_CON 层平行线对(间距100~600)→中心线→shapely 扣柱(COLU 多边形 difference)→按"同宽度+同方向+最近"匹配梁名称编号（含截面文本，无截面标注用同名补全）
- 挡土墙类型/厚度：双线配对得厚度，最近 0 层 DWQ/SCQ 标签定型号，墙高取详图 DIMENSION（geometry block 文本）
- 深区范围用填充 HATCH path 顶点直接成多边形，比墙线闭合可靠；墙线不闭合时用 buffer(R)→取外环→buffer(-R) 形态学闭合
- 承台计数以"承台集中标注"文字为准，几何多边形配最近标签获取每型面积/周长（含倒角准确值）
