## 方法论增量（候选 SKILL.md R23/R24）
- 多图框单模型空间：A0图框带分 sheet；跨图叠合用共有图元锚点（各 sheet 平面不对齐）
- 构件计数可靠做法：同一构件在两张图都出现时（桩在 S2/S3），平移对齐后逐点配对验证
- 膨胀加强带识别：HATCH pattern=ANSI37 长条带 + 平面"膨胀加强带"引出标注；区别于 ANSI31 深区填充（看线层）
- 板洞 vs 降板：板洞边线层 X 标记=洞；说明注列出的填充图例=降板；围合区外的整跨 X=无板区
