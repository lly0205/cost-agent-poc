2026-06-10 完成"阳山卫生间大样 2~4层给排水_布局1.dxf"单层工程量初算（核心筒卫生间：男卫/女卫/无障碍/茶水间），并将方法论固化为 SKILL.md 的 **R22 章节**（布局比例导出 DXF，区别于 R20 的模型空间 1:1 图）。

**Why:** 该图与 R20 适用的 TWT 模型空间图不同——实体在 modelspace 但按出图比例绘制（1单位=50mm），且平面图/系统图同场共存，靠 const_width（w=0 平面 / w=1 系统图）区分；图块语义靠"器具表+图例区+渲染比对"三级映射确定。

**How to apply:** 再遇卫生间大样/装修给排水 DXF，先按 R22 流程：DIMENSION 定比例 → 视图分区 → 器具表/图例映射图块 → 平面管段赋径（长干管在标注处分段）→ 垂直段按横干管标高−器具高度。结果校验用闭合关系（存水弯数=需水封器具数、GS配水点数=用水点数）。

**本案例结论摘要（单层）：** 蹲便器7、小便器4、台式洗脸盆4、坐便器1、残卫洗手池1、拖把池1、污水盆1；地漏5、清扫口4、存水弯18、截止阀7、水表1、减压阀1；给水PPR约72.4m（DN15~DN50）、排水UPVC约44m（de50/75/110）、通气de50约5.3m。给水横干管按距地3.0m，排水大样标注"一层"、按2~4层布置一致假定使用。
