# 人工复核规则

> 本文件定义造价师对 AI 输出进行人工复核的标准流程和检查要点。

## 1. 复核的必要性

AI 辅助造价存在以下固有局限，**人工复核不可省略**：
- AI 无法真正"看懂"图纸（当前版本通过文字描述工作）
- AI 可能误解专业术语或地区规范
- AI 可能遗漏隐含条件（如合同约定、甲方特殊要求）
- AI 输出结果无法承担法律责任

---

## 2. 复核人员要求

| 场景 | 最低要求 |
|------|----------|
| 工程量初算复核 | 具有造价员证或相关专业经验 |
| 正式提交成果 | 注册造价工程师签字盖章 |
| 结算审核 | 注册造价工程师 |
| 诉讼/纠纷场景 | 具有司法鉴定资质的机构 |

---

## 3. 复核检查清单

### 3.1 基础检查（每次必做）

- [ ] AI 输出的 JSON 格式是否完整，是否有异常字段
- [ ] `review_notes` 免责声明是否存在
- [ ] `uncertain_items` 列表是否已全部处理
- [ ] 所有计算式是否可以重现（用计算器验算）
- [ ] 图纸依据是否真实存在（随机抽查 3-5 条）

### 3.2 工程量核查（量大时可抽样）

- [ ] 重点项目（金额大的）逐条核对
- [ ] 计算式是否正确（公式 × 数量 × 系数）
- [ ] 单位是否一致（m、m²、m³、kg、樘等）
- [ ] 有无明显遗漏（对照图纸目录检查）
- [ ] 有无重复计算（同一内容出现两次）

### 3.3 描述核查

- [ ] 项目名称是否准确
- [ ] 项目特征描述是否完整（材料、规格、做法、等级）
- [ ] 是否符合当地清单规范要求

### 3.4 不确定项核查

- [ ] 所有 `uncertain_items` 是否已有处理决定
- [ ] 处理决定（忽略/确认/等待）是否有依据
- [ ] 高优先级不确定项是否已书面确认

---

## 4. 复核结果记录

每次复核后需记录：

```json
{
  "review_date": "YYYY-MM-DD",
  "reviewer": "姓名（资质）",
  "ai_output_file": "文件名",
  "review_result": "通过/有修改/需重新计算",
  "corrections": [
    {
      "item": "被修改的条目",
      "original": "AI 原始值",
      "corrected": "修改后的值",
      "reason": "修改原因"
    }
  ],
  "final_approval": false,
  "notes": "其他说明"
}
```

---

## 5. 复核发现常见问题及处理

| 问题类型 | 处理方式 |
|---------|----------|
| 数量轻微偏差（<2%）| 记录并修正，可接受 |
| 数量明显偏差（>5%）| 逐条分析原因，重新核算 |
| 漏项 | 补充列项，评估对总价影响 |
| 项目描述有误 | 修改描述，确认是否影响单价 |
| 计算式错误 | 重新计算，记录错误原因 |
| AI 编造图纸依据 | 严重问题，记录并提交给团队，改进 AI 输入 |

| 200-500 条 | 3 - 8 小时 |

---

## 7. 最终成果输出规范

AI 辅助造价的最终成果必须：
1. 经过造价师完整复核
2. 造价师对修改内容负责
3. 文件上标注"经人工复核，版本 X.X，复核人：XXX，日期：YYYY-MM-DD"
4. 原始 AI 输出文件存档，不得删除（用于审计和改进）
