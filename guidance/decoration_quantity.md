# 装修工程量初算 Guidance

> 本文件提供装修工程量计算的指导框架。
> **重要**：具体计算规则以项目所在地定额/清单规范为准，以下为通用框架，造价师需根据实际规范补充。

## 1. 楼地面工程

### 1.1 地面铺装（瓷砖、石材、木地板等）

**计算基准**：通常按**净面积**计算
- 扣除：柱、墙占地面积（≥0.3 m² 的才扣，具体看地方规范）
- 不扣除：门洞口（通常不扣）
- 计算式示例：`房间净长 × 净宽 = 地面面积`

**需确认事项（待造价师补充）**：
- [ ] 本项目适用的地方定额/清单规范
- [ ] 地面做法层次（垫层、找平、粘结层、面层各自计算还是综合）
- [ ] 踢脚线是否单独列项

### 1.2 地面找平层

**计算基准**：同地面铺装面积
- 注意：同一空间内不同厚度找平需分别列项

### 1.3 踢脚线

**计算基准**：通常按**延长米**计算
- 扣除：门洞口宽度
- 计算式示例：`周长 - 门洞宽 = 踢脚线长度`

---

## 2. 墙柱面工程

### 2.1 墙面抹灰/涂料

**计算基准**：通常按**净面积**计算
- 高度：楼层净高（板底到地面）
- 扣除：≥0.3 m² 的门窗洞口（具体标准看规范）
- 不扣除：踢脚线、挂镜线占用部分（通常）

**需确认事项**：
- [ ] 内墙面高度取值（含还是不含天花板厚度？）
- [ ] 门窗洞口侧壁是否单独列项

### 2.2 墙面砖

**计算基准**：同墙面抹灰
- 注意：厨房、卫生间墙砖通常贴到顶，高度与其他房间不同

### 2.3 柱面

**计算基准**：柱周长 × 柱净高
- 独立柱与墙柱通常分开计算

---

## 3. 天棚工程

### 3.1 天花板抹灰/涂料

**计算基准**：通常按**水平投影面积**计算
- 扣除：≥0.3 m² 的柱、隔断等（具体看规范）
- 梁底面是否展开计算：看规范要求

### 3.2 吊顶（轻钢龙骨石膏板等）

**计算基准**：吊顶水平投影面积
- 注意：跌级吊顶侧板面积是否另计
- 灯槽/灯带区域做法可能不同

## 6. 常见问题和注意事项

| 问题 | 处理方式 |
|------|----------|
| 图纸未标注房间净高 | 标注为不确定项，等待造价师确认 |
| 门窗尺寸图纸与清单不一致 | 标注差异，等设计确认 |
| 装修方案有多个版本 | 明确以哪个版本为准 |
| 厨卫防水范围不明确 | 列入不确定项 |
| 不同房间使用不同规格材料 | 分别列项 |
