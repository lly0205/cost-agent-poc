# 门窗工程量 Guidance

> 本文件提供门窗工程量计算的指导框架。
> 具体规则以项目所在地定额/清单规范为准，以下为通用框架。

## 1. 门的计算

### 1.1 计量方式

通常有两种（以项目规范为准）：

| 方式 | 说明 | 单位 |
|------|------|------|
| 按洞口面积 | 门洞宽 × 门洞高 | m² |
| 按樘数 | 每一个门计为一樘，配套五金安装 | 樘 |

### 1.2 需从图纸提取的信息

- [ ] 门洞尺寸（宽 × 高），从门窗表或平面图读取
- [ ] 门的类型（木门、钢门、防盗门、防火门、玻璃门、卷帘门等）
- [ ] 门框材料
- [ ] 五金配件等级
- [ ] 是否含门套/贴脸

### 1.3 防火门特殊要求

- 防火门需注明防火等级（甲级/乙级/丙级）
- 防火门通常比普通门单价高，需单独列项

### 1.4 计算示例

```
示例：M-1（木质夹板门）
  图纸依据：一层平面图，轴线 A-B/1-2，门窗表 M-1
  洞口尺寸：900 mm × 2100 mm
  数量：5 樘
  面积计算：0.9 × 2.1 × 5 = 9.45 m²（如按面积计）
  或：5 樘（如按樘数计）
```

## 2. 窗的计算

### 2.1 计量方式

| 方式 | 说明 | 单位 |
|------|------|------|
| 按洞口面积 | 窗洞宽 × 窗洞高 | m² |
| 按樘数 | 每一扇窗计为一樘 | 樘 |

### 2.2 需从图纸提取的信息

- [ ] 窗洞尺寸（宽 × 高），从门窗表或立面图读取
- [ ] 窗的类型（铝合金平开窗、推拉窗、固定窗、飘窗、天窗等）
- [ ] 玻璃类型（单层、中空、夹胶、LOW-E 等）
- [ ] 开启扇比例
- [ ] 是否含窗台板、窗帘盒

### 2.3 外窗节能要求

- 需注意项目是否有节能要求（传热系数要求）
- 不同节能等级的窗价格差异较大

### 2.4 飘窗计算

飘窗通常分开计算：
- 飘窗底板面积（如外挑）
- 飘窗玻璃（三面）
- 飘窗台面

## 3. 门窗表读取方法

从图纸门窗表中通常可以读取：
1. 编号（M-1, C-1 等）
2. 洞口宽 × 高
3. 数量（各楼层分布）
4. 类型说明
5. 备注（特殊要求）

**常见陷阱**：
- 门窗表数量与平面图中标注的数量不一致 → 需提示并等待确认
- 表中尺寸是洞口尺寸还是成品尺寸？ → 需确认（通常清单按洞口）
- 不同楼层相同编号但实际尺寸可能不同（如首层大堂门）

## 6. 常见不确定项

| 不确定情形 | 处理方式 |
|-----------|----------|
| 门窗表缺失 | 标注为不确定项，请求设计提供门窗表 |
| 平面图与门窗表数量不符 | 标注差异，等待设计确认 |
| 特殊造型门窗（弧形、异形） | 标注需单独核价 |
| 改造项目原有门窗处理方式未明确 | 列入不确定项 |
