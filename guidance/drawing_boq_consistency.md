# 图纸与清单一致性检查 Guidance

> 本文件提供图纸与工程量清单（BOQ）一致性核查的检查框架。

## 1. 检查目标

确保：
1. 清单中的每个项目在图纸上都有对应的工程内容
2. 图纸上的每个主要工程内容在清单中都有对应列项
3. 数量、规格、做法的描述前后一致

---

## 2. 逐项检查流程

### Step 1：梳理清单项目

将清单中所有项目列出，逐项在图纸中寻找对应依据：
- 能找到图纸依据 → 标注图纸编号
- 找不到图纸依据 → 标注"图纸未见"，列入不一致项

### Step 2：梳理图纸内容

将图纸中的主要工程内容列出，逐项在清单中寻找对应：
- 清单中已有对应项目 → 核对数量和描述
- 清单中未列 → 标注为"清单漏项"

### Step 3：数量核对

对能计算的项目，用图纸数据重新计算，与清单数量对比：
- 偏差 ≤ 2%：可接受（建议标注）
- 偏差 2%~5%：需注意，标注原因
- 偏差 > 5%：重点标注，需造价师复核
- **注意**：计量方式不同可能导致数量差异（如墙面是否扣门窗洞口）

### Step 4：项目描述核对

清单项目特征描述是否与图纸一致：
- 材料型号/规格
- 做法厚度
- 质量标准/等级
- 施工工艺

---

## 3. 常见不一致类型

| 类型 | 示例 | 严重程度 |
|------|------|----------|
| 清单漏项 | 图纸有防水层，清单无此项 | 高 |
| 清单多项 | 清单有某墙面做法，图纸无此区域 | 高 |
| 数量偏差 > 5% | 清单地面 100m²，图纸算出 120m² | 中-高 |
| 材料规格不符 | 清单写 600×600 砖，图纸写 800×800 | 中 |
| 做法描述不符 | 清单写 20mm 抹灰，图纸做法表写 15mm | 中 |
| 项目描述模糊 | 清单仅写"墙面处理"，未说明具体做法 | 低-中 |

---

## 4. 输出格式

每个不一致项需包含：
```
{
  "item": "项目名称",
  "boq_ref": "清单编号",
  "drawing_ref": "图纸编号+位置",
  "discrepancy": "不一致描述",
  "severity": "高/中/低",
  "action": "建议处理方式"
}
```

---

## 5. 特殊情况处理

### 5.1 清单比图纸"超前"

有时清单中包含图纸未画出但合同中有要求的内容（如配合甲方采购的材料）：
- 不能简单标注为"漏项"
- 需注明"依据合同/甲供材料清单，非图纸依据"

### 5.2 图纸有多个版本

- 必须确认使用哪个版本的图纸
- 不同版本图纸间的差异本身就是一个不确定项

### 5.3 改造项目

- 需区分新增、拆除、保留部分
- 原有工程量的确认方式（图纸 vs 实测）需明确
