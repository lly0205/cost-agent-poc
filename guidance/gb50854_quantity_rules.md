# GB50854-2013 算量规则速查

> 本文件在算量任务中自动加载，提供清单计算规则的关键摘要。

## 永久生效强制规则

**Rule 1** — 框架柱、构造柱必须扣除现浇楼板板厚，按净高（= 层高 - 板厚）计算体积。

**Rule 2** — 砌体墙必须扣除门窗洞口体积/面积；洞口尺寸严格取自图纸《门窗表》，不得估算。

## 高频构件计算要点

### 混凝土柱（010502001/010502002）
- 净高 = 层高 - 板厚（Rule 1强制）
- **有梁板**：柱基上表面 → 上一层楼板上表面
- **无梁板**：柱基上表面 → 柱帽下表面
- **框架柱**：柱基上表面 → 柱顶（全高）
- 牛腿、升板柱帽并入柱身体积
- 构造柱：嵌接墙体马牙槎体积并入

### 混凝土梁（010503002）
- 长度：柱（墙）侧面之间的净距
- 不重复计算与柱相交节点

### 混凝土板（010505001有梁板 / 010505003平板）
- **有梁板**：梁+板体积之和合并计算；板头并入板体积
- **无梁板**：板+柱帽体积之和
- 压形钢板楼板：扣除压形钢板所占体积
- 不扣 ≤ 0.3㎡ 的柱、垛、孔洞

### 砌体墙（010401003/010402001）
- 体积 = 长度 × 净高 × 厚度 - 门窗洞口体积 - 嵌入RC构件体积
- 外墙长度按中心线；内墙长度按净长
- 不扣：梁头板头、≤0.3㎡孔洞、钢管等

### 门窗（010801001 等）
- 计量单位可选樘或㎡（洞口面积）
- 洞口面积 = 宽 × 高（按门窗表）

### 钢筋（010515001）
- 工程量 = 图示长度 × 理论单重
- 伸出构件的锚固钢筋并入工程量（即图示已含锚固）
- **施工搭接**（设计未标注）不另计工程量，在综合单价中综合考虑
- 常用单重：φ8→0.395kg/m，φ12→0.888kg/m，φ16→1.578kg/m，φ20→2.466kg/m，φ25→3.853kg/m

### 土方
- 沟槽：底宽≤7m且底长>3倍底宽
- 基坑：底面积≤150㎡且底长≤3倍底宽
- 工程量 = 垫层底面积 × 挖土深度（不放坡时）

### 屋面/防水（面积类）
- 坡屋面按斜面积；平屋面按水平面积
- 防水层面积 = 屋面面积（含卷起高度）

### 墙面抹灰（011201001）
- 扣除：墙裙、门窗洞口、单个 > 0.3㎡ 的孔洞
- 不扣：踢脚线、挂镜线、墙与构件交接处
- 洞口侧壁及顶面**不增加**面积
- 附柱、梁、垛、烟囱侧壁并入相应墙面
- **外墙**：垂直投影面积
- **外墙裙**：长度 × 高度
- **内墙**：主墙间净长 × 高度（无墙裙→地面至天棚底；有墙裙→墙裙顶至天棚底）
- **内墙裙**：内墙净长 × 高度

### 措施项目
- 综合脚手架、垂直运输 = 建筑面积（按 **GB/T 50353-2013** 计算，已确认）
- 模板 = 与混凝土接触面积

## 基础工程计算要点（2026-06-08 新增）

> 来自 D01#~D04# 卫生间结构算量实操，永久生效。

### 基础梁判定
- **无地下室单体**：一层所有梁（KL框架梁 + L次梁）均为**基础梁**，编码 010503001
- 判断步骤：图纸有无地下室 → 无 → 一层所有梁归基础梁

### 垫层（010501001）
- **适用范围**：承台 + 所有基础梁（含次基础梁）底部，缺一不可
- **尺寸**：垫层宽 = 基础宽 + 200mm（每边外扩100mm）；厚100mm；C20素砼
- **体积**：垫层宽 × 净跨 × 0.1m（梁下）；(承台长+0.2)×(承台宽+0.2)×0.1（承台下）
- **模板**（侧面粘灰面）：
  - 梁下：2 × 净跨 × 0.1m（两长侧面，端头不计）
  - 承台下：(长+宽)×2 × 0.1m（四侧面）

### 承台（010501003 / 010501005）
- **尺寸读取**：①1-1剖面详图标注 ②高度=顶标高-底标高 ③DXF坐标差值
- **混凝土**：长×宽×高×数量
- **模板**（侧面粘灰面）：(长+宽)×2×高×数量

### 基础梁模板（011702001）
- 基础梁（含次基础梁）：**仅两侧面** = 梁高×2×净跨×根数
- 楼层梁/屋面梁：**三面** = (梁高×2+梁宽)×净跨×根数

### 梁跨数判断（22G101-1）
1. 集中标注括号内数字优先（KL1(2) → 2跨）
2. 无括号：跨数 = 支座数 − 1
3. 无法判断：默认1跨，标注 ⚠️

### 开始算量前必问项
若以下信息缺失，先提问再计算：
- [ ] 混凝土强度等级
- [ ] 有无地下室
- [ ] 多栋楼各栋桩长是否相同
- [ ] 承台详图尺寸是否清晰
