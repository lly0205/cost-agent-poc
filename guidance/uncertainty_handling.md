# 不确定项处理规则

> 本文件定义如何识别、记录和处理造价工作中的不确定内容。
> **核心原则：宁可标注不确定，不要猜测。**

## 1. 什么是不确定项

以下情况必须标注为不确定项，不得猜测：

| 情况 | 说明 |
|------|------|
| 图纸信息缺失 | 图纸未标注的尺寸、做法、材料 |
| 图纸自相矛盾 | 不同图纸或同图纸不同位置数据矛盾 |
| 地区规则差异 | 计算规则因地区而异且未明确 |
| 做法不明确 | 仅有示意图，无详细做法说明 |
| 数据来源不清 | 不确定某数字来自图纸还是经验 |
| 需要现场核实 | 旧建筑改造中原有结构不明 |
| 合同约定不明 | 某费用是否在合同范围内不确定 |
| 甲供材料未确认 | 是否由甲方采购的材料未明确 |

---

## 2. 不确定项记录格式

每条不确定项需包含以下信息：

```json
{
  "id": "UC-001",
  "item": "不确定项的简要描述",
  "reason": "为什么不确定（图纸未标注/图纸矛盾/需现场核实等）",
  "impact": "对工程量或造价的影响（如：影响地面面积约 XX m²）",
  "action_required": "需要谁来做什么（如：请设计出具补充说明）",
  "priority": "高/中/低",
  "status": "待确认"
}
```

---

## 3. 不确定项优先级划分

| 优先级 | 判断标准 | 示例 |
|--------|----------|------|
| 高 | 不确认无法继续算量，或影响超过 5% 总量 | 主要房间层高未标注 |
| 中 | 影响部分工程量，但整体可继续推进 | 某区域做法说明缺失 |
| 低 | 影响较小或可用常规做法暂估 | 角落细部收口方式 |

---

## 4. 不确定项的处理流程

```
发现不确定项
    │
    ▼
记录到 uncertain_items 列表
    │
    ▼
评估影响范围
    │
    ▼
高优先级？── 是 ──▶ 暂停该部分计算，等待确认
    │
    否
    │
    ▼
可否用"保守假设"继续？── 是 ──▶ 标注"暂按 XX 计算，待确认"
    │
    否
    │
    ▼
标注"未计入，待确认后补充"
```

## 5. 常见不确定项示例库

> 以下示例供参考，实际项目中需根据情况调整。

### 装修工程常见不确定项

- 图纸未标注楼层净高 → 影响墙面面积计算
- 卫生间防水高度未明确（全贴还是局部？）
- 图纸门窗表与平面图数量不符
- 天花板做法说明缺失（是否有吊顶？材料？）
- 踢脚线材料和高度未标注

### 土建工程常见不确定项

- 图纸未注明混凝土强度等级
- 钢筋锚固长度未明确（需看结构说明）
- 基础类型变更依据不明确

### 安装工程常见不确定项

- 末端设备型号未确定
- 管道走向与建筑图冲突
- 预埋件是否在土建范围内

## 6. 不确定项的 AI 行为规范

AI 在处理不确定项时必须：

✅ **允许的行为**：
- 标注不确定项并说明原因
- 提供多种可能的情况及其对应工程量范围（标注为估算）
- 告知造价师需要补充哪些信息

❌ **禁止的行为**：
- 直接填入一个"合理估计"的数字而不标注不确定
- 假设最常见的做法并按此计算（除非明确标注）
- 忽略图纸矛盾，选择其中一个版本而不说明
